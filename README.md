# Responsive Frontend Website

## 📌 Project Overview

This project is a fully responsive frontend website built using **HTML5, CSS3, and JavaScript**. It demonstrates the fundamentals of modern web development, including responsive layouts, interactive user interfaces, and basic client-side functionality.

The project was developed as part of a frontend web development learning journey and focuses on creating a clean, responsive, and user-friendly website.

## 🚀 Features

* Responsive Navigation Bar
* Hero Section
* Feature Cards
* Services Section
* Contact Form with Validation
* Dark/Light Mode Toggle
* Back-to-Top Button
* Smooth Scrolling
* Mobile-Friendly Design
* Hover Effects and Animations

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)

## 📖 What I Learned

* Creating web page structures using HTML5
* Styling responsive layouts with CSS3
* Using Flexbox for modern layouts
* Building responsive designs with Media Queries
* Adding interactivity using JavaScript
* Handling DOM events
* Creating and validating forms
* Implementing Dark Mode
* Improving user experience with smooth scrolling and animations

## ▶️ How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

No additional software or installation is required.
